## サーバーレンタルの費用相場は種類で数十倍から100倍以上開く

同じ「レンタルサーバー」でも、共用サーバーと専用サーバーでは相場が数十倍から100倍以上違います。まずどちらの種類が必要なのかを決めないと、価格比較そのものが意味を持ちません。

KAGOYAが公表している相場は次のとおりです。

| 種類 | スペック目安 | 月額相場 | 年額相場 |
| --- | --- | --- | --- |
| 共用サーバー（低） | 簡単なWebサイト向け | 800円 | 8,500円 |
| 共用サーバー（中） | 集客も行うサイト向け | 1,400円 | 15,500円 |
| 共用サーバー（高） | 大量アクセスサイト向け | 2,500円 | 28,000円 |
| 専用サーバー（中） | ページ数の多いサービスサイト | 25,000円 | 280,000円 |
| 専用サーバー（高） | アクセス量の多いECサイト | 50,000円 | 550,000円 |
| 専用サーバー（最高） | 大規模な複数サイト運用 | 100,000円 | 1,100,000円 |

共用サーバーは複数の利用者で1台をシェアする形態です。事前に最低限の設定が済んでいるため、申請から1〜2時間程度で使い始められます。安い代わりにカスタマイズ性が低く、同じサーバーを使う他のサイトの負荷が上がると自分のサイトも重くなる、という構造的な弱点があります。

価格差が生まれる理由は主に3つ。ハードウェアのスペック差、サポート体制の人員と品質、そして契約期間の長さによる割引です。「安い」という一言で比較すると、この3つのどれを削っているのかが見えなくなります。

## 費用は月額ではなく「初期費用込みの年間総額」で見る

月額表示だけで選ぶと、実際の支払額とズレます。初期費用がかかるプラン、年払いでしか適用されない価格、逆に短期契約のほうが割高になるケースが混在しているためです。

格安共用サーバー9社を比較した記事では、初期費用と年間料金を合計した年間コストが最安2,640円から約7,500円まで、約2.8倍の差があると報告されています。この比較は2023年6月公開の記事で、価格の基準時点を「2026年4月時点の通常価格」と明記したものです。現在の実売価格とは動いている可能性がある点は差し引いて読む必要があります。

それでも、月額200円前後のプランが並んでいて年間でこれだけ開くという事実は参考になります。具体的な数字で見ておきます。

- コアサーバー CORE-MINI：初期費用無料、月額約220円〜、300GB SSD、30日間の無料お試し。ただし **CORE-MINIは後からプラン変更ができない**。
- バリューサーバー スタンダード：初期費用2,200円、月額約366円〜、400GB SSD、10日間の無料お試し。
- バリューサーバー まるっとプラン：初期費用無料、36ヶ月契約で月額137円〜。ただし **無料お試しの対象外**。
- ロリポップ ライト：初期費用無料、月額約330円〜、10日間の無料お試し。バックアップは有料オプション。
- さくらのレンタルサーバー スタンダード：初期費用無料、月額約500円〜、14日間の無料お試し。

ここで見えてくるのが、安さの裏側にある条件です。36ヶ月縛りにすれば月額は下がるが試せない、月額を下げるとプラン変更が効かない、バックアップを外すと容量単価が下がる。年間総額を計算するときは、この「縛り」も一緒に確認したほうがいいでしょう。

年払いの効果を実感しやすい例がKAGOYA自身の価格表です。1コア/4GBのプランは月額契約が1,650円、年額契約が17,820円。12で割ると月あたり1,485円になり、月払いを12回払うより年間で約2,000円安くなります。2コア/8GBなら月額5,500円が年額59,400円（月あたり4,950円）、4コア/16GBなら月額11,000円が年額118,800円（月あたり9,900円）。スペックが上がるほど年払いの絶対額の差も広がります。

なお、独自ドメインが無料で付くサーバーは月額600〜1,000円台が一般的です。ドメイン込みの総額で比べたい場合は、この水準を一つの物差しにしておくと判断しやすくなります。

## 同スペックでもRyzenとEPYCで差が出る理由

同じMini・Air・Proという名前でも中身が違うので、単純に「上位プラン＝高性能」で選ぶと損をします。

- Mini：Ryzenが$59、EPYCが$39。差額$20。vCPU・メモリ・容量・流量は同じで、ポートが2Gbps対1Gbps。
- Air：Ryzenが$99、EPYCが$79。差額$20。同じくポートのみ2Gbps対1Gbps。
- Pro：Ryzenが$199、EPYCが$169。差額$30。ここは構成が逆転します。**Ryzen Proは6vCPU・5Gbps、EPYC Proは8vCPU・3Gbps**。

Proに関しては、コア数重視ならEPYC、ポート速度重視ならRyzen、という選び分けになります。月額30ドル差を払ってコア数を2つ減らす価値があるかは用途次第です。単一スレッド性能が効くゲームサーバーやビルド処理ならRyzen、並列処理や多数のコンテナを動かすならEPYCのほうが筋が通ります。

更新の仕組みも独特です。期日の7日前に更新請求書が自動発行され、メール通知が届きます。クレジットカードを登録していれば自動課金も試行されます。そして期日を過ぎると即座に停止。ドキュメントには「猶予期間はない」とはっきり書かれています。

- 期日当日：即時停止（データは保持され、支払えば自動復旧）
- 期日から5日後：サービス終了。データは復旧できない可能性がある

督促は1日遅延、2日遅延、3日遅延の3段階で届きますが、停止自体は期日当日に実行されます。「メールを見ていなかった」では済まない設計です。継続利用が決まっているなら、口座残高を事前チャージして自動更新に備えるか、期日より前に手動で支払うのが安全でしょう。

現在のサイクルが終われば更新時に別のサイクルへ変更できますが、途中で即時に切り替えたい場合はサポートへの連絡が必要です。

## 見落としやすい制限と、契約後に発生する追加コスト

月額に含まれないもの、契約後に発覚しやすい制限をまとめておきます。プラン表だけでは見えない部分です。

**バックアップは自分で取る前提**

利用規約に、GoMamiは顧客データのバックアップを行わず、データ消失について責任を負わないと明記されています。定期的な自身でのバックアップが推奨されています。国内の共用サーバーなら自動バックアップが付くプランも多いので、この点は条件が明確に違います。

**流量はアウトバウンドのみ、月次でリセット**

プランに含まれる流量はアウトバウンド（送信）のみがカウントされ、インバウンド（受信）は課金対象外です。割り当て量は各請求サイクルの開始時にリセットされます。不足した場合は追加の流量パックを購入できますが、単価は公開情報では明示されていないため、必要になりそうなら購入前にサポートへ条件を確認しておくほうが確実です。

**プラン変更はセルフサービスではない**

現在、プラン変更はチケットシステム経由でサポートに連絡する必要があります。ダッシュボードから自分で切り替えることはできません。急にリソースが足りなくなったときは、そのやり取りの分だけタイムラグが発生します。

**支払い方法と返金の条件**

支払い方法はクレジット／デビットカード（Stripe）、Alipay（Stripe Alipay）、暗号資産の3系統です。返金はサービス有効化から24時間以内の新規購入のみが対象で、1人1回限り。更新注文は対象外です。返金申請はチケットのBillingカテゴリから行い、到着までの日数はAlipayが1〜3営業日、クレジットカードが5〜10営業日と案内されています。

規約側には追加の除外条件が並んでいます。DDoS攻撃を受けた場合、24時間以内に1台のVMで10GBを超える流量が出た場合、暗号資産決済の注文（最終取引として扱われ返金対象外）。返金が承認されると、該当インスタンスとデータは即時かつ永久に削除されるため、申請前のバックアップが必須です。

24時間という短さは、月額数百円の共用サーバーにある10日〜30日の無料お試しとはかなり性格が違います。実質的に「初期不良や接続不良の確認期間」と考えるほうが近いでしょう。ただし初回のみとはいえ全額返金の窓口があるのは、月額39ドルから始めるうえでの判断材料になります 👉 [GoMamiの24時間返金ポリシーとプラン詳細を確認する](https://bit.ly/Gomami)
